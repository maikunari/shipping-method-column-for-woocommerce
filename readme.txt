Adds a shipping method column to the WooCommerce orders list page for easy visibility of shipping methods used on each order.

== Description ==

WooCommerce Shipping Method Column is a simple yet powerful plugin that enhances your WooCommerce order management by adding a dedicated shipping method column to the orders list page in the WordPress admin.

= Key Features =

* **Easy Visibility**: See shipping methods at a glance without opening individual orders
* **Multiple Methods Support**: Displays all shipping methods if an order has multiple shipping items
* **Clean Display**: Shows "No shipping" for orders without shipping methods
* **Lightweight**: Minimal impact on performance with efficient code
* **No Configuration Required**: Works immediately after activation

= Perfect For =

* Store owners who need to quickly identify orders by shipping method
* Fulfillment teams processing orders based on shipping type
* Stores with multiple shipping options that need better order organization
* Anyone looking to improve their WooCommerce order management workflow

== Installation ==

1. Upload the `woocommerce-shipping-method-column` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Navigate to WooCommerce > Orders to see the new Shipping Method column

= Manual Installation =

1. Download the plugin zip file
2. Log in to your WordPress admin panel
3. Navigate to Plugins > Add New > Upload Plugin
4. Choose the downloaded zip file and click 'Install Now'
5. Activate the plugin after installation

== Frequently Asked Questions ==

= Does this plugin require any configuration? =

No, the plugin works immediately after activation. No settings or configuration needed.

= Will this work with my theme? =

Yes, this plugin works with any theme as it only modifies the admin order list page.

= Can I customize the column position? =

Currently, the column appears after the Order Status column. Custom positioning may be added in future versions.

= Does it work with HPOS (High-Performance Order Storage)? =

The plugin is compatible with WooCommerce's traditional post-based order storage. HPOS compatibility will be added in a future update.

= Will this slow down my admin panel? =

No, the plugin is optimized for performance and adds minimal overhead to the orders page.
